# FinanceCo Static Page

A simple React and Vite single-page finance website.

## Structure

- `src/App.jsx` contains the router and shared page shell.
- `src/components/common` contains the reusable header and footer.
- `src/pages` contains one folder per route.
- `src/pages/Home/components` contains the Home page sections.
- `src/pages/Home/homeData.js` contains Home page content and image data.
- `src/index.css` contains the global theme and shared styles.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```
